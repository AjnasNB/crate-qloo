# Technical QA: sixteen checks

Developed by Ajnas N B

Reviewed on October 17, 2026. This ledger records actual source inspection and local checks of the working tree. A pass applies to the stated check, not to the entire product or submission. Real Qloo access and customer evaluation remain pending. No live Qloo response, reader result, sales effect or winning probability was invented.

## Changes made during this review

- Reproduced a stock-validation bug: a book with quantity zero and reserve two could be ignored while the planner returned a feasible plan. The planner now rejects any reserve exceeding stock. The MCP tool rejects the same invalid inventory before consuming a Qloo request.
- Reproduced an import/API mismatch: a quoted SKU containing an embedded newline imported successfully but could not pass live evidence validation. CSV import now rejects control characters inside SKUs while retaining ordinary spaces and ISBN punctuation.
- Added three regression tests. The independent optimization generator now samples physically valid reserves from zero through quantity; invalid reserves have a separate rejection test. Its 220 exhaustive comparisons still exercise feasible/infeasible plans, missing rankings, constraints and repairs.

## Remaining acceptance gates

The integrated production build and version 3 publication are verified. Before exposing a real key, confirm ignored local secret files and the upstream hard quota or deployment abuse controls. Then perform the live experiment in [VALIDATION.md](VALIDATION.md), including one real external-agent tool session and a changed-programme query. If inventory coverage or useful cultural differences fail, revise the premise rather than substituting fixtures.

Qloo matches works, not promised ISBN editions. The live adapter requires unique confirmed Qloo book entities; separate edition/SKU rows mapping to the same work currently need consolidation before a live request. This is a bounded prototype limitation, not evidence that those editions have distinct cultural affinities.
